# 🚦 Automated Railway Gate System using IoT

This project is an **IoT-based Automated Railway Gate Control System** built with **Arduino, RFID, Servo Motor, LCD, Buzzer, and LEDs**.  
It simulates how railway gates automatically close when a train approaches and open after the train passes, ensuring safety at railway crossings.

---

## 📌 Features
🚉 Detects train movement using **RFID sensors** placed at different distances (2 km, 1 km, at gate).  
🚦 Automatically closes/open the gate using a **servo motor**.  
🔊 Provides **alerts** using buzzer and LEDs (Red/Green).  
📟 Displays real-time status on **16x2 I2C LCD**.  
 ↔ Supports **two-way train movement (A → B and B → A)**.

---

## 🛠️ Components Used
Arduino Uno (or compatible board)  
RFID RC522 Reader Modules (4x)  
RFID Tags (attached to train model)  
Servo Motor (for gate control)  
16x2 LCD with I2C module  
LEDs (Red, Green)  
Buzzer  
Jumper wires, Breadboard
